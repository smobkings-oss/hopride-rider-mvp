# HopRide Rider App MVP

Premium ride-hailing rider experience for Northwest Ohio.

## Features
- Instant and Scheduled ride requests
- Upfront fare estimates
- Black/Gold holographic branding
- Local storage demo for ride history
- Ready for Supabase + Maps + Stripe integration

## Tech Stack
- Next.js 15 (App Router)
- TypeScript
- Tailwind CSS
- Lucide icons (ready)

## Next Steps
1. Connect Supabase for auth, database, and realtime
2. Add Google Maps / Mapbox for pickup/dropoff and live tracking
3. Stripe for payments
4. Driver matching logic
5. Capacitor for native mobile apps

## Development
```bash
npm install
npm run dev
```

Built for A2B Rides / HopRide launch.
